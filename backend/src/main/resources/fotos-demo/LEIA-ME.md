# Fotos dos carros (demonstração)

Coloque aqui uma foto real de cada modelo da frota. O nome do arquivo é `marca-modelo`
em minúsculas, sem acento, com a extensão `.jpg`, `.jpeg`, `.png` ou `.webp` (até 3 MB;
o ideal é ~150 KB, já que a foto é guardada uma vez por carro no banco):

| Arquivo esperado           | Carro                |
|----------------------------|----------------------|
| `volkswagen-fusca.jpg`     | Volkswagen Fusca     |
| `volkswagen-brasilia.jpg`  | Volkswagen Brasília  |
| `chevrolet-opala.jpg`      | Chevrolet Opala      |
| `chevrolet-chevette.jpg`   | Chevrolet Chevette   |
| `ford-galaxie.jpg`         | Ford Galaxie         |
| `ford-corcel.jpg`          | Ford Corcel          |
| `dodge-dart.jpg`           | Dodge Dart           |
| `willys-itamaraty.jpg`     | Willys Itamaraty     |
| `simca-chambord.jpg`       | Simca Chambord       |
| `puma-gte.jpg`             | Puma GTE             |

Ao iniciar o back-end, cada automóvel que ainda não tem foto recebe a do seu modelo
(`DadosDemo.anexarFotos`). Carros que já têm foto não são alterados; use a tela
**Frota** para trocar a foto de um carro específico.

Dica: use fotos do Wikimedia Commons (licença livre) e guarde o crédito do autor no README.
